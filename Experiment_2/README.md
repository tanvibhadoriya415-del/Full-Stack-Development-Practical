# Experiment 2: Interactive Quiz and Weather Dashboard

## Aim
To create an interactive web page using HTML, CSS, and JavaScript.

## Description
This experiment combines a quiz application with a weather dashboard. The quiz includes a 30-second timer and a leaderboard that stores scores in the browser's local storage. The weather section uses the Open-Meteo API to display weather information.

## Features
- Interactive quiz with a countdown timer
- Score tracking
- Leaderboard using local storage
- Weather dashboard using Open-Meteo API

## Technologies Used
- HTML
- CSS
- JavaScript
- Open-Meteo API

## How to Run
Open `index.html` in a web browser. An internet connection is needed for the weather data.
