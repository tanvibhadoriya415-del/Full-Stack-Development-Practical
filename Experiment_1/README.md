# Experiment 1: Institute Webpage

## Aim
To create a static webpage for an institute using HTML.

## Description
This experiment contains an institute webpage for MITS Gwalior. It uses HTML to organize the page content, including a header, navigation, institute information and footer.

## Technology Used
- HTML

## Files
- `index.html` — webpage structure and content

## How to Run
Open `index.html` in a web browser.
